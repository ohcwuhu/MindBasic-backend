# 卡片规范 v1

本知识库的最小知识单元是**卡片**，一张卡 = 一个可被教练对话直接调用的技法、原则或边界规则。

## 一、为什么是卡片

原 15 本书按 500 字正文切块后，实测 6992 个片段里 11.0% 是目录/图表残留、7.8% 是 OCR 乱码，
且片段单位是"作者的论述段落"而非"可执行的动作"，检索命中后无法直接进入回复。

卡片把单位换成"一个场景 → 一个动作 → 一组话术"，检索命中即可用。

## 二、文件与命名

- 一张卡一个 `.md` 文件，放在 `02-技法卡/`（或 `01-安全与边界/`、`03-阶段映射/`）下。
- 文件名格式：`<层>-<家族代号>-<序号>-<卡片中文名>.md`，例如 `L1-SFBT-01-奇迹问句.md`。
- 每张卡必须带 YAML front matter，正文按固定小节书写。

## 三、front matter 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 全局唯一，小写英文加连字符 |
| `layer` | 是 | `L0` 安全边界 / `L1` 技法 / `L3` 阶段映射 |
| `family` | 是 | 技法家族，如 `焦点解决SFBT` |
| `title` | 是 | 卡片中文名 |
| `source_book` | 是 | 理论出处书名 |
| `source_author` | 是 | 作者 |
| `themes` | 是 | 主题标签，检索过滤用 |
| `triggers` | 是 | 用户口语触发词，用用户会说出口的话写，只参与检索、不进入注入内容 |
| `stage` | 是 | 适用的五阶段，取值见下表 |
| `emotion` | 是 | 典型入口情绪词 |
| `risk_max` | 是 | 允许使用的最高风险等级，`NONE` / `LOW` / `MEDIUM` / `HIGH` |
| `when` | 是 | 触发条件（人话，可被关键词命中） |
| `avoid_when` | 是 | 禁用条件 |
| `intensity` | 是 | 情绪强度要求：`低` / `中` / `高` |

### stage 取值

统一使用平台五阶段引擎的命名：`建立`、`探索`、`目标`、`行动`、`收束`。

### risk_max 规则

- `NONE`：任何风险等级都不能用（例如需要用户做深度情绪暴露的练习）。
- `LOW`：低风险及以下可用，绝大多数技法卡用这一档。
- `MEDIUM`：中风险可用（例如角色边界、伦理自检）。
- `HIGH`：高风险时仍必须可用（例如危机分级、转介、稳定化）。

检索规则：`risk_max` 低于当前风险等级的卡片一律不放行；
且当前风险 ≥ `MEDIUM` 时，只放行 `01-安全与边界/` 下的卡片。

## 四、正文小节

每张卡按顺序写这 7 节，缺一不可；每节控制在 450 字以内，便于按节切块。

```
## 一句话原理
## 什么时候用
## 引导语（可直接说）
## 追问链
## 完整示例
## 常见做错的地方
## 出处
```

## 五、写作要求

1. **引导语必须能直接朗读**，不要写"可以引导用户思考……"这类元描述。
2. **示例必须是一问一答的真实口吻**，用户话要像学生会说的话。
3. **禁忌要具体**，写"不要说'你只要换个角度想'"，而不是"注意沟通方式"。
4. `source_book` 是理论归属，卡片正文用自己的表达重写，不复制原书段落。
5. `triggers` 是召回的关键。同一张卡的正文里往往不会出现用户的口语说法
   （用户说"睡不着"，正文写的是"入睡节律调整"），必须显式补上。

## 六、索引与检索

`_工具/build_kb_v2.py` 会递归扫描本目录，解析 front matter，
建立带元数据的 BM25 索引，并支持按 `stage` / `risk_max` / `themes` 过滤后再检索。
