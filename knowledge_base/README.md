# 心理教练自建知识库

本目录是为「斐思同行 / MindBasic」心理教练智能体重建的知识库。
原有 `心理教练智能体知识库-精选15本/` 保持不变，本目录独立可用。

## 为什么重建

原库把 15 本书按 500 字正文切块，实测 6992 个片段中：

- 11.0% 是目录与图表残留；
- 7.8% 是 OCR 乱码；
- 片段单位是"作者的论述段落"，检索命中后无法直接进入回复。

重建后的最小单位是**卡片**：一张卡 = 一个场景 → 一个动作 → 一组可直接朗读的话术。

## 目录结构

```
心理教练知识库-自建/
├─ README.md
├─ _规范/卡片规范.md              卡片 schema 与写作要求
├─ _工具/build_kb_v2.py           带元数据的索引构建与检索
├─ _工具/eval_set.yaml            评测集（问题 → 应命中卡片 → 应触发的行为）
├─ 01-安全与边界/                 L0，风险处置与伦理红线，优先级最高
├─ 02-技法卡/                     L1，主体内容，按家族编号
├─ 03-阶段映射/                   L3，五阶段与技法路由
├─ 04-主题索引/                   L2，书目与主题对照，用于溯源（不参与检索）
└─ 05-场景入口/                   按用户第一句话定位路径（不参与检索）
```

## 与现有后端的接法

1. 构建索引：

   ```powershell
   cd 项目代码\MindBasic-backend
   python ..\..\心理教练知识库-自建\_工具\build_kb_v2.py build
   ```

2. 自检检索：

   ```powershell
   python ..\..\心理教练知识库-自建\_工具\build_kb_v2.py query "我明天要面试了特别焦虑"
   ```

3. 把新索引接入现有检索：`kb_service.py` 的 `context_block_smart` 可替换为
   本工具的 `retrieve()`，并新增 `stage` / `risk_max` 过滤参数。
   （接入改造属于代码改动，需单独确认后执行。）

## 实测结果

在 36 条人工标注评测集上（详见 `_工具/评测报告.md`）：

| 指标 | 重建前基线 | 第一轮（53 卡） | 第二轮（68 卡） |
| --- | --- | --- | --- |
| Recall@4 | 75.0% | 100.0% | 100.0% |
| MRR | 0.635 | 0.969 | 0.978 |
| 寒暄时正确不注入 | 25% | 100% | 100% |
| 召回内容中的目录/OCR 噪声 | 18.8% | 0% | 0% |
| 索引体积 | 18.1 MB | 0.35 MB | 0.44 MB |

过滤策略：风险是硬约束（≥ MEDIUM 时只放行 L0 安全卡），阶段是软约束（不匹配降权 0.6），
分数低于门限则不注入。

## 设计约束

- 每张卡的每个 `##` 小节控制在 450 字以内，保证按小节切块时不被腰斩。
- `risk_max` 决定风险等级下的放行范围，风险 ≥ MEDIUM 时只放行 `01-安全与边界/`。
- 卡片正文为原创表述，`source_book` 记录理论出处，用于学术引用与溯源。
