## 一句话原理

优势不是"我比别人强的地方"，而是"我做起来有劲、做完有满足感"的地方。
找优势是为了给行动一个用得上的入口，不是夸人。

## 什么时候用

- 用户通篇讲自己的缺点。
- 用户做决定时只看"应该"不看"擅长"。
- 需要把资源导向行动时。

## 引导语（可直接说）

三个入口找优势，用哪个都行：

> "有哪件事，你做着会觉得时间过得特别快？"
> "有哪件事，做完之后你会觉得'这件事我做得不错'？"
> "别人遇到什么问题时，会来找你？"

## 常见优势方向（用于帮用户命名）

好奇心 / 好学 / 判断力 / 创造力 / 洞察力 / 勇气 / 坚持 / 正直 / 热心 /
爱与被爱 / 团队协作 / 公平 / 领导 / 自制力 / 谨慎 / 谦逊 / 审美 / 感恩 /
希望 / 幽默 / 信仰

## 完整示例

用户：我也不知道自己擅长什么，感觉什么都很普通。

你：换个问法。有哪件事，你做的时候会觉得时间过得特别快？

用户：跟社团做活动策划的时候吧，一弄就弄到很晚也不觉得累。

你：那件事里你具体在做什么？

用户：想流程、想可能会出什么岔子，提前把坑填上。

你：这听起来是"提前预判风险"，还带着一点组织的成分。
最近有哪件事，你能用上这个？

## 常见做错的地方

- 把优势测试当成贴标签，测完给用户一个结果就结束。
- 只盘不用，找不到落地场景，用户感觉像做了个心理测验。
- 替用户下定义："你最大的优势就是共情力强。"——要让用户自己说。
- 用优势否定痛苦："你有这么多优点，还有什么好难过的。"
