## 一、本项目自研与第三方的边界

| 类别 | 内容 |
| --- | --- |
| **团队自研** | 五阶段状态引擎（`app/services/coach_stage_service.py`）、规则化动态权重与线索冲突检测（`app/services/ai_lab/fusion_service.py`）、置信度校准接入（`calibration.py`）、危机四级规则与工单（`crisis_rules.py`）、实时音视频编排与留痕（`socket_events.py`、`ai_coaching_service.py`）、平台前后端 |
| **第三方模型** | SenseVoiceSmall（语音转写）、emotion2vec+ large（语调情感）、mDeBERTa-v3（文本情感）、DeepFace（面部表情） |
| **第三方工具/服务** | FunASR、openSMILE、DeepSeek API、Dify（工作流编排）、豆包等 OpenAI 兼容 Vision API、edge-tts |

自研部分不包含任何模型训练或微调；所有模型均为开源权重或第三方 API 调用。
